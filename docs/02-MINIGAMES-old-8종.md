# 02 · 미니게임 8종 명세

> 엔진에 8종을 만들어 두고 시대마다 **재사용**합니다.
> 새 시대를 위해 미니게임을 새로 만들지 마세요. 소재를 8종 중 하나에 맞추는 편이 빠르고, 아이도 조작법을 다시 배우지 않아도 됩니다.

---

## 0. 공통 규약

### 호출 방식

퀘스트 객체에 `kind:'minigame'`과 `mini` 블록을 넣습니다. 엔진이 `mini.type`으로 고릅니다.

```js
const startFn = MINIGAME_STARTERS[q.mini.type] || startMinigame;
```

`type`을 지정하지 않으면 **기본형**으로 넘어갑니다. 오류가 아니라 설계된 동작입니다.

### 판정 시점 — **누르는 순간**

버튼의 `click` 은 **손을 뗄 때** 옵니다. 누르고 떼는 사이(80~150ms)에 바늘이 화면의
10~20%를 지나가 "제대로 눌렀는데 빗나감"이 생깁니다. 판정은 `pointerdown` 으로 하세요.
자세한 것은 [12-BUILD-RULES.md](12-BUILD-RULES.md) §3.

### 흐름

미니게임 앞에는 **반드시 선택형 문제가 먼저** 옵니다. 무작정 조작부터 시키지 않고, 왜 그렇게 해야 하는지 먼저 판단하게 합니다.

```
story  →  q (선택형)  →  정답  →  mini.intro  →  조작  →  mini.ok
                        └ 오답 → q.no → 다시
```

### 공통 필드

| 필드 | 필수 | 쓰임 |
|---|---|---|
| `type` | ✕ | 없으면 기본형 |
| `intro` | **○** | 조작 화면 상단 설명 |
| `ok` | **○** | 성공했을 때. 역사적 의미를 여기서 마무리합니다 |
| `retry` | △ | 실패했을 때. 실패가 있는 종류는 필수 |
| `tag` | ✕ | 화면 상단 짧은 라벨 (`판소리 · 장단에 맞추어 북 치기`) |
| `startLabel` | ✕ | 시작 버튼 문구 (`활터로 가기 →`) |
| `hitLabel` | ✕ | 조작 버튼 문구 (`🥁 북 치기`) |

### 실패를 막다른 길로 만들지 않는다

**초등학생이 씁니다.** 실패해도 `retry`를 보여 주고 다시 도전할 수 있어야 합니다. 시도 횟수 제한은 긴장감을 위한 것이지 배제를 위한 것이 아닙니다.

---

## 1. `spin` — 돌리기

원반을 손가락으로 **원을 그리듯 돌립니다.**

| 항목 | 값 |
|---|---|
| 성공 조건 | 누적 회전이 `laps` 바퀴 |
| `laps` 기본값 | 4 |
| 실패 | **없음** |
| 추가 필드 | `laps` |

포인터 각도의 변화량을 누적합니다. 방향은 상관없고 절댓값으로 셉니다. 진행에 따라 가운데 원이 커지며 `n / 4 바퀴`로 표시합니다.

**쓰임**: 물레로 백자 빚기, 숫돌에 자개 갈기, 맷돌 돌리기처럼 **일정한 힘으로 오래 반복하는 일**.

실패가 없어서 가장 부담이 적습니다. 시대의 첫 미니게임으로 쓰기 좋습니다.

---

## 2. `knap` — 당겼다 놓기

버튼을 **누르고 있으면** 게이지가 차오릅니다. **놓는 순간** 게이지 끝이 목표 구간 안이면 명중입니다.

| 항목 | 값 |
|---|---|
| 성공 조건 | 6번 안에 4번 명중 |
| 충전 시간 | 1초에 100% |
| 목표 구간 | 처음 26% → 명중할수록 좁아짐 (최소 11%) |
| 구간 위치 | 매번 무작위 |
| 실패 | 6번 시도 후 명중 4회 미만 |

**너무 오래 누르면 게이지가 끝까지 차서 빗나갑니다.** 힘이 아니라 때를 재는 감각을 요구합니다.

**쓰임**: 활쏘기, 돌 떼어내기(뗀석기), 작살 던지기.

---

## 3. `ember` — 불씨 지키기

불씨가 **계속 사그라듭니다.** 버튼을 눌러 살리되, 너무 자주 누르면 지나치게 타오릅니다.

| 항목 | 값 |
|---|---|
| 성공 조건 | 적정 구간에 `holdMs`만큼 머물기 |
| `holdMs` 기본값 | 6000ms |
| 적정 구간 | 40 ~ 75 |
| 감소 속도 | 초당 13 |
| 한 번 누를 때 | +16 |
| 쿨다운 | 450ms |
| 시작 레벨 | 55 |
| 실패 | 레벨이 0 |

색으로 상태를 알려 줍니다. **낮으면 붉은빛 · 적정이면 초록 · 높으면 주황.** 적정 구간에 있는 동안만 시간이 쌓입니다.

**쓰임**: 봉수대 불 지키기, 불씨 살리기, 가마 온도 맞추기, 야간 경계.

8종 중 가장 **긴장감이 높습니다.** 시대의 절정에 배치하세요.

---

## 4. `stack` — 순서대로 쌓기

섞여 있는 단계 버튼을 **올바른 순서대로** 누릅니다. 맞을 때마다 그림의 해당 부분이 나타납니다.

| 항목 | 값 |
|---|---|
| 성공 조건 | 모든 단계를 순서대로 |
| 실패 | 실수 3회 |
| 추가 필드 | `steps` (**필수**), `visual` (**필수**) |

### `steps`

```js
steps:['지게를 바로 세운다',
       '가장 무거운 소금 자루를 맨 아래에 얹는다',
       '옹기를 그 위에 올린다',
       '가벼운 무명 필을 맨 위에 얹는다',
       '끈으로 단단히 동여맨다']
```

**4~5단계가 적당합니다.** 3단계면 너무 쉽고, 6단계를 넘으면 아이가 지칩니다.

### `visual`

`viewBox="0 0 200 170"` 기준의 인라인 SVG 문자열입니다. 단계마다 `data-step`을 붙인 `<g>`로 감쌉니다.

```html
<rect x="0" y="142" width="200" height="28" fill="#C9C2A8" opacity=".5"/>
<g class="stack-part" data-step="0"> ... </g>
<g class="stack-part" data-step="1"> ... </g>
```

`data-step`의 개수가 `steps`의 개수와 **반드시 같아야 합니다.**

> **`visual`을 빠뜨리면 기본 그림(막집 모양)이 나옵니다.** 오류가 나지 않아서 모르고 지나치기 쉽습니다. 금속 활자 조판에 막집이 나온 적이 있습니다.

**쓰임**: 탑 쌓기, 봇짐 꾸리기, 갑옷 입히기, 움집 짓기, 성벽 쌓기, 활자 조판.

아래에서 위로 쌓이는 소재에 가장 잘 맞습니다.

---

## 5. `grind` — 좌우 번갈아 타이밍

바늘이 좌우로 왕복합니다. **지정 구간을 지날 때** 누릅니다. 성공하면 다음은 반대쪽 차례입니다.

| 항목 | 값 |
|---|---|
| 성공 조건 | 10번 안에 6번 명중 |
| 목표 구간 | 처음 22% → 명중할수록 좁아짐 (최소 9%) |
| 속도 | 2회마다 빨라짐 (3단계) |
| 좌우 교대 | 명중할 때마다 반대쪽 |
| 실패 | 10번 시도 후 명중 6회 미만 |

화면에 `왼쪽 날을 밀 차례 · 3 / 6`처럼 표시됩니다.

> 초기에는 **좌우를 아무 생각 없이 번갈아 누르기만 하면** 통과됐습니다. 그래서 타이밍 판정을 넣어 다시 설계했습니다. 아이가 화면을 보지 않고도 깰 수 있으면 게임이 아닙니다.

**쓰임**: 판소리 장단, 맷돌 갈기, 붕대 감기, 톱질.

---

## 6. `lift` — 단발 타이밍

`grind`와 같은 왕복 바늘이지만 **좌우 교대가 없고**, 명중할 때마다 물체가 조금씩 올라갑니다.

| 항목 | 값 |
|---|---|
| 성공 조건 | 8번 안에 5번 명중 |
| 구간 위치 | 매번 무작위 (16~74% 사이) |
| 시각 효과 | 명중 비율만큼 물체가 상승 |
| 실패 | 8번 시도 후 명중 5회 미만 |

**쓰임**: 거중기로 성돌 올리기, 투호, 씨름, 두레박 긷기.

`grind`보다 쉽습니다. 좌우를 신경 쓰지 않아도 되기 때문입니다.

---

## 7. `sort` — 두 갈래로 가려내기

카드가 하나씩 나옵니다. 왼쪽 통과 오른쪽 통 중 맞는 쪽으로 **끌어다 놓습니다.**

| 항목 | 값 |
|---|---|
| 성공 조건 | 전체의 **70% 이상** 정답 |
| 실패 | 70% 미만 |
| 추가 필드 | `items` (**필수**), `binLeftIcon/Label`, `binRightIcon/Label` |

### `items`

```js
items:[
  {icon:'♨️', label:'온돌',      korean:true },   // 왼쪽 통
  {icon:'🛣️', label:'주작대로',  korean:false},   // 오른쪽 통
  ...
]
```

`korean` 필드 이름이 어색하지만 **왼쪽/오른쪽을 가르는 불리언**입니다. `true`가 왼쪽입니다.

**10개 안팎, 좌우를 절반씩** 넣으세요. 한쪽으로 치우치면 아이가 규칙을 알아채기 전에 찍어서 70%를 넘깁니다.

**쓰임**: 재래 작물과 새 작물, 고구려 계승과 당 수용, 우리 것과 들어온 것.

8종 중 **교육적으로 가장 강합니다.** "발해가 고구려를 이어받았다"를 말로 설명하는 대신, 아이가 유물을 직접 갈라 놓으면서 스스로 알아차립니다.

---

## 8. `memory` — 순서 기억하기

불빛이 정해진 순서로 켜집니다. **그 순서 그대로** 되누릅니다. 한 라운드를 넘길 때마다 길이가 하나씩 늘어납니다.

| 항목 | 값 |
|---|---|
| 성공 조건 | `rounds` 라운드를 모두 통과 |
| `rounds` 기본값 | 4 |
| 시작 길이 | 2 |
| 마지막 길이 | `2 + rounds - 1` (기본 5) |
| 실패 | **한 번이라도 틀리면 즉시** |

즉시 실패라 8종 중 **가장 가혹합니다.** `rounds`를 4보다 크게 잡지 마세요.

**쓰임**: 상륙 신호, 암호 주고받기, 봉수 신호 순서.

## 8-1. `blank` — 빈칸 채우기 (10번째 형식)

문장 속 `____` 에 낱말을 써 넣습니다. 콘텐츠 문서에 네 번 나옵니다
(`04-samguk` 첨성대 · `09-joseon-late` 실학 · `12-war` 두 곳).

| 항목 | 값 |
|---|---|
| 성공 조건 | 공백·문장부호를 지운 뒤 `정답` 과 같으면 통과 |
| 실패 | 없음 — 틀리면 `no` 를 보여 주고 다시 쓰게 합니다 |
| 표기 | 역할 선택이면 `**형식**: 빈칸 채우기 문제`, 조사형 마무리면 `**미니게임 종류**: \`blank\`` |

**쓰임**: 이름을 스스로 떠올리게 하고 싶을 때. 선택지를 주면 찍어서 넘어갑니다.

## 9. 기본형 (`type` 없음)

가장 단순한 왕복 바늘 타이밍입니다.

| 항목 | 값 |
|---|---|
| 성공 조건 | 3번 안에 2번 명중 |
| 실패 | 3번 시도 후 명중 2회 미만 |

**추가 필드가 없어도 돌아갑니다.** `intro`와 `ok`만 있으면 됩니다. 급할 때 쓰세요.

**쓰임**: 망치질, 담금질처럼 "정확한 순간에 내리치기".

## 10. 고를 때

| 소재의 성격 | 쓸 것 |
|---|---|
| 일정하게 오래 반복 | `spin` |
| 정확한 한 순간 | `knap` · 기본형 |
| 계속 지켜보며 유지 | `ember` |
| 순서가 중요 | `stack` |
| 리듬·박자 | `grind` |
| 힘을 모아 들어 올리기 | `lift` |
| 분류·비교 | `sort` |
| 기억 | `memory` |

### 시대마다 확인할 것

- **미니게임이 0개인 시대가 없게 하세요.** 통일신라·발해가 그랬습니다.
- 한 시대에 **같은 종류를 두 번 쓰지 마세요.** 조작이 똑같아서 아이가 금방 알아챕니다.
- 시대당 **2~4개**가 적당합니다. 너무 많으면 이야기가 끊깁니다.
