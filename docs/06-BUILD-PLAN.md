## 1. 사람 배치

세 명 기준입니다. 두 명이면 지도 담당을 나머지 둘이 나눠 갖습니다.
배정 근거는 [08-BUILD-ORDER.md](08-BUILD-ORDER.md) Phase 표입니다.

| | 담당 | 주로 여는 문서 | 건드리는 파일 |
|---|---|---|---|
| **엔진 담당** | 엔진 · 미니게임 10형식 · `grader` · **콘텐츠 변환 규칙** · 레지스트리 병합 | 01, 02, 12 §6 | `js/engine/*`, `js/eras/*`(변환분) |
| **소품 담당** | 시대별 전용 3D 소품 (시대를 나눠 맡음) | 09, `content/*` | `js/eras/<자기 시대>.js` |
| **지도 담당** | 지도 모드 · 학습 항목 신규 20개 · 에셋 · 인쇄 | 04, 07, 10 | `js/map-*`, `js/atlas-*`, `js/report.js`, `assets/` |

**엔진 담당이 병목입니다.** 엔진 뼈대가 끝나야 나머지가 시작할 수 있습니다. 그래서 다른 일을 맡지 않습니다.

## 2. 시작하는 순서

```
    지도 담당 ─ 누락 에셋 수집 (백그라운드로 계속)
    │
    엔진 담당 ─ 엔진 뼈대 ──→ 미니게임 10형식 ──→ 변환 규칙 ──→ 12시대 일괄 변환
                │
                ├──→ 소품 담당 ─ 시대별 전용 3D 소품
                │
    지도 담당 ─────────────→ 지도 모드 · 항목 20개 · 인쇄
                          │
    다같이 ────────────────→ 검증 · 배포
```

### 인수인계 지점 세 곳

**① 엔진 담당 → 소품 담당 (엔진 뼈대 완료)**
엔진 담당이 이 문장을 말하면 소품 담당이 시작합니다.

> "빈 월드 하나로 3D 씬이 뜨고 캐릭터가 움직인다. `scene-helpers`의 빌더 목록은 이렇다."

소품 담당은 그 빌더 목록으로만 지형을 짭니다. 목록에 없는 게 필요하면 **자기 시대 파일 안에서** 만듭니다.

**② 엔진 담당 → 전원 (미니게임 완료)**
**10형식을 전부 만드는 것이 기준입니다.** 콘텐츠 문서가 10형식을 모두 쓰기 때문에 하나라도 빠지면 그 퀘스트가 깨집니다 — 특히 `blank` 는 16번 쓰여 가장 많습니다.

**③ 전원 → 엔진 담당 (등록)**
`worlds-registry.js`는 **모두가 건드리는 유일한 파일**입니다. 각자 고치면 충돌합니다.

> 시대 파일만 각자 만들고, 등록은 **엔진 담당이 마지막에 몰아서** 합니다.

## 3. 각자의 "끝났다"

### 엔진 담당

- [ ] 빈 월드에서 캐릭터가 걷고 뛰고 시야가 돌아간다
- [ ] 퀘스트 마커를 눌러 카드가 열리고 완료 처리된다
- [ ] 새로고침해도 완료 상태가 남아 있다
- [ ] 미니게임이 **성공·실패 양쪽 모두** 정상 종료된다
- [ ] `collectContent`가 없는 항목을 만나도 영문 id를 노출하지 않는다
- [ ] 시대 두 개 이상을 타임라인에서 오갈 수 있다

### 소품 담당 — 시대 하나

- [ ] 타임라인에서 들어가 `발견 0 / N`이 뜬다
- [ ] 지역이 여럿이면 **관문으로 오갈 수 있고 돌아올 수 있다**
- [ ] 퀘스트 하나를 완료해 역사 가방에 담긴다
- [ ] 마커가 겹쳐서 못 누르는 곳이 없다
- [ ] 형식이 섞여 있다 (역할 선택 / 열린 선택 / 조사형 / 미니게임)
- [ ] 지역별 퀘스트 수가 한쪽으로 몰리지 않는다

### 지도 담당 — 지도 모드

- [ ] 지도가 한반도로 보인다
- [ ] 시대를 옮기면 영역이 바뀐다
- [ ] 항목을 눌러 상세가 열린다
- [ ] 도감이 채워진다
- [ ] 사진마다 저작자·라이선스가 보인다

## 5. 버릴 때의 규칙

시간이 모자라면 **아래에서부터** 버립니다. 위쪽을 버리면 앱이 성립하지 않습니다.

```
버리면 안 됨   엔진 · 미니게임 10형식 · 탐험 12시대 전부 · 지도 모드 기본
       ↑
       │       시대별 전용 3D 소품  → 공용 빌더로 대체
       │       사진 · GLB 모델
       │       한 시대 안에서 퀘스트 개수 줄이기
       ↓
먼저 버림      (정말 마지막에만) worlds-registry 에서 시대 빼기
```

**시대를 빼지 마세요.** 콘텐츠 이전은 규칙 하나로 12개가 한꺼번에 되므로, 모자라는 것은 언제나 "그 시대의 3D 소품"이지 "그 시대" 자체가 아닙니다. **빈 시대가 하나도 없는 편이 데모에서 훨씬 낫습니다** — [08-BUILD-ORDER.md](08-BUILD-ORDER.md) 1장.

**사진과 GLB가 없어도 앱은 돕니다.** 사진 없는 항목은 화면에서 자연스럽게 생략되고, GLB 대신 기본 도형이 나옵니다.

**소품에 힘을 줄 셋**: 삼국 · 조선 후기 · 광복과 6·25.
영토 변화가 가장 잘 보이는 시대, 생활사가 풍부한 시대, 미니게임이 가장 많은 시대라 서로 다른 재미를 보여 줍니다.

## 6. 커밋 규칙

- **시대 파일은 각자 커밋**해도 충돌하지 않습니다
- `worlds-registry.js`는 **엔진 담당만** 커밋합니다
- `index.html`·`css/styles.css`는 Phase 0 이후 거의 건드릴 일이 없어야 정상입니다. 필요하면 **자기 모드 컨테이너 안쪽**에만
- 남의 담당 파일을 고쳐야 하면 **말하고 고치세요.** 조용히 고치면 다음 병합에서 사라집니다

---

## 7. 마지막 한 시간

기능 추가를 멈추고 이것만 합니다.

1. 새 탭에서 콘솔 오류 0건 확인
2. 인터넷을 끊고 두 모드가 모두 뜨는지
3. 태블릿 크기에서 조이스틱 좌우가 맞는지
4. 배포하고 **실제 URL에서 한 번 더** 열어 보기
5. 출처·라이선스 표기 확인

**4번을 빠뜨리지 마세요.** 로컬은 대소문자를 가리지 않지만 배포 서버는 가립니다. `vendor/`와 `assets/` 경로에서 자주 터집니다.
