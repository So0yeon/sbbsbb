# 04 · 지도 모드 (2D SVG)

> 탐험 모드와 **완전히 다른 코드**입니다. three.js도 ES 모듈도 쓰지 않습니다.
> 평범한 `<script>`와 SVG로 만듭니다.
>
> 두 모드를 잇는 것은 **`contentId` 하나뿐**입니다. ([01-ARCHITECTURE.md](01-ARCHITECTURE.md) 6장)

---

## 1. 무엇을 하는 화면인가

하나의 지도 위에서 **시대를 옮겨 다니며** 영토가 변하는 것을 봅니다. 유물·인물·사건은 **지도 위 제자리에** 찍힙니다.

교과서는 시간(연표)은 주지만 공간은 시대별로 흩어진 지도로만 줍니다. **하나의 지도가 시간에 따라 변하는 것**을 보는 경험은 종이가 줄 수 없고 화면이 가장 잘하는 일입니다.

### 화면 구성

```
┌─────────────────────────────────────────┐
│  [학생용][교사용]  [🧭 탐험 모드][📗 도감] │
│                                          │
│              SVG 지도                     │
│         (영역·도읍·화살표·항목 마커)        │
│                                          │
│  [+][−][전체]         분류 필터            │
│                                          │
│  ◀ 구석기 신석기 청동기 … 6·25 ▶  (타임라인) │
└─────────────────────────────────────────┘
        항목을 누르면 ↑ 상세 시트가 올라옴
```

## 2. 좌표계

**모든 좌표는 `[위도, 경도]` 순서입니다.** 저장소 전체가 이 순서입니다. `[경도, 위도]`로 쓰면 지도가 뒤집힙니다.

```js
const MAP = { lng0:115, lng1:137, lat0:30, lat1:49, w:800, h:902 };
const px = lng => (lng - MAP.lng0) * (MAP.w / (MAP.lng1 - MAP.lng0));
const py = lat => (MAP.lat1 - lat) * (MAP.h / (MAP.lat1 - MAP.lat0));
```

단순 정거원통 투영입니다. 정확한 도법보다 **아이가 알아보는 모양**이 중요합니다.

`path(pts)`가 `[[위도,경도], …]` 배열을 SVG `d` 문자열로 바꿉니다.

> **`MAP` 상수는 `map-data.js`와 `atlas-geo.js`가 반드시 같아야 합니다.**
> 다르면 해안선과 마커가 어긋납니다.

## 3. 데이터 스키마

### 3-1. 시대 (`ERAS`)

```js
{ id:'three', name:'삼국시대', short:'삼국',
  years:'기원전 57 ~ 668', span:'고구려·백제·신라·가야',
  line:'세 나라가 한강을 두고 겨루고, 남쪽에서는 가야가 …',
  accent:'#4E7F6A',                    // 이 시대의 색
  view:[33.2,121.5,43.8,131.2],        // 기본 지도 범위 [남,서,북,동]
  terr:[…],                            // 나라 영역
  nb:[…] }                             // 이웃 나라 표시
```

| 필드 | 설명 |
|---|---|
| `id` | 탐험 모드의 월드 id와 맞추세요 |
| `short` | 타임라인에 들어갈 짧은 이름 |
| `span` | 한 줄 부제 |
| `line` | 아이에게 보여 줄 한 문장 요약 |
| `accent` | 시대를 구분하는 색 |
| `view` | 시대를 고르면 이 범위로 카메라가 움직임 |

### 3-2. 나라 영역 (`terr`)

```js
{ n:'고구려', c:'#4E7F6A', at:[41.6,125.4],
  pts:[[45.0,123.5],[44.8,130.5], …],       // 영역 폴리곤
  cap:{ n:'평양', at:[39.02,125.75] },       // 도읍
  kr:1 }                                     // 육지에 맞춰 자를 것인가
```

`kr:1`이면 **육지 폴리곤과 교차 연산**해서 경계가 바다로 삐져나가지 않게 합니다.
`kr` 이 없는 영역(고구려·발해 등)도 **대륙 육지로는 잘라야 합니다** — 안 자르면 영역이
동해로 번집니다. 클립을 두 벌 두세요([12-BUILD-RULES.md](12-BUILD-RULES.md) §5-1). 이게 "한반도로 보인다"를 만드는 핵심입니다. ([07-ASSETS.md](07-ASSETS.md) 4장)

**고조선처럼 학계가 합의하지 못한 경계는 점선으로 표시합니다.** 결함이 아니라 "학자마다 다르게 본다"를 가르칠 수 있는 자리입니다.

### 3-3. 항목 (`CONTENT`)

```js
{ id:'jeongok', era:'paleo', cat:['relic'], t:'연천 전곡리',
  at:[38.02,127.06],
  d:'한탄강 가에서 구석기 시대의 주먹도끼가 무더기로 나온 곳이에요.',
  b:['본문 문단 1', '본문 문단 2'],
  tags:['주먹도끼','뗀석기','한탄강'],
  rel:['makjip','seokjangni'] }
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `id` | ○ | 전체에서 고유. **탐험 퀘스트의 `contentId`가 이걸 가리킵니다** |
| `era` | ○ | `ERAS`의 id |
| `cat` | ○ | 배열. 여러 분류에 걸칠 수 있음 |
| `t` | ○ | 이름 |
| `at` | ○ | `[위도, 경도]` |
| `d` | ○ | 한 줄 설명 |
| `b` | ○ | 본문 문단 배열 |
| `tags` | ✕ | 검색·연결용 |
| `rel` | ✕ | 관련 항목 id. 상세에서 이어 볼 수 있음 |

### 3-4. 분류 (`CAT`)

여섯 가지입니다. 각각 색과 아이콘(SVG path)을 갖습니다.

| id | 이름 |
|---|---|
| `relic` | 유물·유적 |
| `person` | 인물 |
| `culture` | 문화 |
| `event` | 사건 |
| `exchange` | 교류 |
| `life` | 생활문화 |

**새 분류를 늘리지 마세요.** 필터 UI와 도감이 여섯 개를 전제로 만들어져 있습니다.

## 4. 기능

### 4-1. 타임라인

하단에 시대가 나열되고, 누르면 그 시대의 `view` 범위로 카메라가 부드럽게 이동합니다. 영역·도읍·항목이 함께 바뀝니다.

단원 구분을 함께 보여 줍니다.

```js
UNIT = i => i<=6 ? '1단원 · 선사 시대 ~ 고려'
           : (i<=9 ? '2단원 · 조선과 개항' : '3단원 · 일제강점기 ~ 6·25')
```

### 4-2. 지도 조작

- 확대·축소 버튼과 휠
- 드래그로 이동
- "시대 전체 보기" 버튼
- 항목을 누르면 그 자리로 초점 이동

**라벨이 겹치지 않게 재배치하는 로직이 필요합니다.** 마커가 몰리는 경주·한양 일대에서 이름이 서로 가립니다.

### 4-3. 상세 시트

항목을 누르면 아래에서 시트가 올라옵니다.

```
사진 (있으면)
이름 · 분류 배지
한 줄 설명
본문 문단들
확인 문제 (있으면)
관련 항목  →  누르면 이어서 열림
출처 · 저작자 · 라이선스
```

**사진이 없는 항목이 많습니다(146개 중 105개).** 없으면 그 자리를 자연스럽게 비우세요. 빈 액자를 보여 주지 마세요.

### 4-4. 유물 도감

본 항목이 색으로 채워집니다. 탐험 모드의 **역사 가방과 같은 저장소**를 씁니다.

```js
localStorage['historyBagExplore_v1']
```

탐험에서 퀘스트를 깨면 지도 모드 도감도 채워집니다. **두 모드를 잇는 유일한 보상 장치**입니다.

### 4-5. 학생용 / 교사용

```js
localStorage[MKEY] = 'student' | 'teacher'
```

교사용에서만 학습지 인쇄가 보입니다. 학생 화면을 단순하게 유지하기 위해서입니다.

### 4-6. 학습지 인쇄

교사가 고른 항목으로 종이 학습지를 뽑습니다.

| 종류 | 내용 |
|---|---|
| 조사 학습지 | 항목별 빈칸. 아이가 찾아 적음 |
| 문제지 | 확인 문제 모음 |
| 오려 쓰는 카드 | 잘라서 분류·배열 활동 |
| 정답지 | 교사용 |

머리말에 `학년 __ 반 __ 이름 __`이 들어가고, 정답지에는 `교사용 · 배부 전 확인하세요`가 찍힙니다.

**"교사가 종이로도 쓸 수 있어야 한다"가 이 프로젝트의 요구 조건입니다.** 태블릿이 없는 교실이 여전히 많습니다.

## 5. 얹기 구조

`map-data.js`와 `map-app.js`는 **고치지 않습니다.** `atlas-*.js`가 그 위에 얹힙니다.

```html
<script src="js/map-data.js"></script>      <!-- 원본 -->
<script src="js/atlas-geo.js"></script>     <!-- 실측 해안선·강·음영기복 -->
<script src="js/atlas-content.js"></script> <!-- 항목 추가 -->
<script src="js/atlas-photos.js"></script>  <!-- 사진 68장 -->
<script src="js/asset-credits.js"></script>
<script src="js/map-app.js"></script>       <!-- 원본 -->
<script src="js/atlas-later.js"></script>   <!-- 후삼국 보강 -->
<script src="js/atlas-dedupe.js"></script>  <!-- 중복 정리 -->
<script src="js/atlas-integrate.js"></script><!-- 지도·도감·교사 기능 얹기 -->
```

### 배열을 갈아 끼우지 말고 내용만 바꾸세요

`map-app.js`가 이미 `KOREA`·`ASIA` 배열을 **참조로 붙잡고** 있습니다. 통째로 새 배열을 대입하면 그쪽은 옛것을 계속 봅니다.

```js
function refill(target, source) {
  target.length = 0;
  for (var i = 0; i < source.length; i++) target.push(source[i]);
}
```

**이걸 모르고 대입했다가 실측 해안선이 화면에 안 나온 적이 있습니다.**

### 중복 항목

두 팀이 같은 유물을 다른 이름으로 넣은 곳이 46군데였습니다. `atlas-dedupe.js`의 스위치 하나로 고릅니다.

```js
const DUP_MODE = 'keep-both';   // keep-ours | keep-theirs | keep-both
```

> `keep-ours`로 바꾸면 탐험 퀘스트가 `theirs` 쪽 `contentId`를 참조하던 연결이 끊깁니다. 바꾸기 전에 탐험 모드를 확인하세요.

## 6. 함정

### SVG `clipPath` 안에 `<g>`를 넣지 마세요

**규격상 무시됩니다. 브라우저가 오류를 내지 않습니다.** 음영기복이 통째로 사라졌는데 화면을 직접 보기 전까지 몰랐습니다.

### 좌표의 출처를 한 파일로 못박으세요

좌표가 두 곳에 나뉘어 있어서, 지도를 다시 그릴 때마다 한쪽이 덮어써졌습니다. **마커가 절반만 표시되는** 증상이었습니다.

### 눈대중 좌표로 한반도를 그리지 마세요

40점짜리 손 좌표로는 아무리 다듬어도 한반도로 보이지 않습니다. Natural Earth 실측(`assets/countries-50m.json`, 1:50m)을 쓰세요.

시간이 없어 실측 데이터를 못 넣는다면, **단순한 윤곽으로 먼저 만들고 나중에 갈아 끼우세요.** `atlas-geo.js`만 나중에 붙이면 됩니다.

## 7. 끝났다고 볼 기준

- [ ] 지도가 한반도로 보인다
- [ ] 시대를 옮기면 영역과 도읍이 바뀐다
- [ ] 항목을 눌러 상세가 열리고, 관련 항목으로 이어 볼 수 있다
- [ ] 분류 필터가 동작한다
- [ ] 도감이 채워지고, **탐험 모드에서 깬 것도 반영된다**
- [ ] 교사용에서 학습지가 인쇄된다
- [ ] 사진마다 저작자·라이선스가 보인다
- [ ] 라벨이 겹쳐 읽을 수 없는 곳이 없다

## 지도 모드 데이터 원문 (ERAS · CONTENT)

> 팀원 수연 님이 정리한 내용입니다.

### `ERAS` 배열 — 시대 순서/영역/이웃나라/교류선

**지도 모드는 13개 시대**를 다룹니다(탐험 모드는 12개 — **광복(`liberation`)만 지도 모드에 따로 있고**, 탐험 모드에서는 6·25와 한 시대로 묶여 있습니다). 순서(=`eraIdx`, 타임라인 순서)와 정확히 일치해야 함: `paleo, neo, bronze, three, unified, later, goryeo, joseon_e, joseon_l, open, colonial, liberation, war`(13개).

각 항목 필드: `id, name, short(타임라인 표시용 짧은 이름), years, span(부제), line(한줄설명), accent(hex, 그 시대 테마색 — 지도 필터/헤더에 즉시 반영), view:[lat0,lng0,lat1,lng1](카메라 기본 뷰), terr:[국가별 영역](없으면 빈 배열), nb:[이웃나라 라벨](없으면 빈 배열), rel:[교류/전쟁 관계선](없으면 생략 가능)`.

`terr` 항목: `{n:이름, c:색, at:[lat,lng](라벨 위치), pts:폐곡선 좌표배열(또는 `[배열,JEJU]`처럼 여러 폐곡선을 합친 배열 — 예: 제주도가 그 나라 영역에 포함될 때), kr:1(있으면 한반도만 클립, 없으면 대륙까지 클립 — landclip vs krclip), cap:{n:수도이름,at:[lat,lng]}(있으면)}`.

`rel` 항목: `{id, t:이름, ty:유형라벨, from:[lat,lng], to:[lat,lng], bend:곡률(-1~1, 0=직선), d:설명문단}`.
