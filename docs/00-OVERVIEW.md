## 2. 왜 만드는가

초등 5-2 사회는 **한 학기 만에 구석기부터 현대까지** 달립니다. 20여 차시에 국사 전체를 나눠야 하니 수업은 사건과 연도를 훑고 지나갑니다.

교실에서 이런 장면이 반복됩니다.

- **"고구려가 어디예요?"** — 나라 이름은 외우지만 **어디에 있었는지**를 그리지 못합니다. 교과서 지도는 시대마다 따로 떨어져 있어 영토가 **움직인다**는 감각이 생기지 않습니다.
- **"이게 언제 거예요?"** — 유물 사진은 봤는데 어느 시대 것인지 연결이 안 됩니다.
- **역사가 남의 일** — 연표 위 숫자로만 다가와, 그 시대를 살았던 사람의 선택으로 느껴지지 않습니다.

교사에게도 빈틈이 있습니다. 수업에 쓸 시대별 지도를 매번 검색해 캡처하고, 우리 지역 문화재를 넣고 싶어도 자료를 고칠 방법이 없습니다.

### 목표

> 아이가 **"그때 그곳"** 을 지도 위에서 그릴 수 있게 한다.
> 교사가 **자기 수업에 맞게 고쳐 쓸 수 있게** 한다.

## 3. 지켜야 할 제약

이 넷은 타협하지 않습니다.

| 제약 | 왜 |
|---|---|
| **서버 없음** | 학생 개인정보가 나갈 통로 자체를 만들지 않습니다. 저장은 `localStorage`뿐 |

## 4. 기술 스택 (고정)

| 구분 | 사용 |
|---|---|
| 프런트엔드 | **바닐라 JavaScript · SVG · CSS** (프레임워크 없음) |

| 지도 데이터 | Natural Earth 1:50m — `assets/countries-50m.json` (퍼블릭 도메인) |
| 지오메트리 처리 | Python · Shapely |
| 이미지 | 위키미디어 공용 · 국가유산청 |
| 저장 | 브라우저 `localStorage` |
| 배포 | 정적 파일 (GitHub Pages) |

### 왜 프레임워크를 안 쓰는가

빌드 도구가 없으면 **파일을 열면 바로 돕니다.** 8~14시간 안에 만들고, 다른 교사가 받아서 고쳐 쓸 수 있어야 합니다. `npm install`부터 시작하는 도구는 교실에 남지 않습니다.

### 모듈 방식이 두 가지입니다

- **탐험 모드** — ES 모듈 (`import`/`export`)
- **지도 모드** — 평범한 `<script>` 전역

섞지 마세요. 지도 모드는 나중에 `atlas-*.js`가 위에 얹히는 구조라 전역이어야 합니다.

## 8. 남은 과제 (정직하게)

이전 결과물에서 해결하지 못한 것들입니다. 숨기지 말고 그대로 안고 가세요.

- **영역 경계는 근사치입니다.** 해안선·산맥·하천은 실측이지만, 시대별 국경은 교과서를 참고해 그린 것입니다. 역사 전공 교사의 검수가 필요합니다.
- **고조선 경계는 학계 미확정**이라 점선으로 표시했습니다. 이건 결함이 아니라 **"학자마다 다르게 본다"를 가르칠 수 있는 지점**이라고 봅니다.
- **일부 항목이 중복**됩니다. 두 팀의 자료를 합치면서 생겼습니다. `atlas-dedupe.js`의 스위치로 고를 수 있게 해 두었습니다.
- **사진 없는 항목이 많습니다** (146개 중 105개).

### 충돌 방지 — 공용 파일 규칙

`index.html`과 `css/styles.css`는 **양쪽 모드가 공유**합니다. 두 팀이 동시에 건드리면 병합 충돌이 납니다.

1. **가장 먼저(개발 시작 직후 30분 이내)**, 누군가 한 명이(보통 엔진 담당) `index.html` 뼈대(인트로 + 두 모드의 빈 DOM 컨테이너, 아래 §"index.html 뼈대" 참고)와 `css/styles.css`의 디자인 토큰(`:root` 변수, [`03-DESIGN-SYSTEM.md`](03-DESIGN-SYSTEM.md) 참고)을 스캐폴딩하고 커밋 → 이후 각자 자기 영역만 추가.
2. 이후 `index.html`에 새 DOM을 추가할 때는 **자기 모드의 최상위 컨테이너(`#app`=지도모드, `#explore`=탐험모드) 내부에만** 추가 — 서로의 컨테이너는 건드리지 않음.
3. `css/styles.css`도 섹션 주석(`/* ── 지도 모드 ── */`, `/* ── 탐험 모드: 미니게임 ── */` 등)으로 나뉘어 있으니 그 관례를 유지 — 자기 섹션에만 추가.
4. `asset-credits.js`는 공용 — 새 에셋 파일을 추가한 사람이 자기 항목만 배열 끝에 덧붙임(다른 사람 항목 삭제 금지).
