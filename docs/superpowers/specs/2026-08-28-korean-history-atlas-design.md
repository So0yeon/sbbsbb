## 1. 문체 규약 (D1·D2 확정판)

### 1-1. 어느 곳이 어느 문체인가

| 자리 | 문체 | 예 |
|---|---|---|
| 탐험 모드 — 상황·나레이션 | `~다체` / `이니라` | "그대는 시간의 틈에 휩쓸려 이곳에 닿았다." |
| 탐험 모드 — 묻는 말·해설·NPC 대사 | **하오체** | "이 토기는 어찌하여 밑을 뾰족하게 만들었소?" |
| 탐험 모드 — 선택지 | 1인칭 다짐 (그대로) | "같은 방향으로 여러 번 쳐 내자!" |
| 탐험 모드 — UI 문구·두루 대사·등급·스탬프 | 하오체 | "가방을 여시오", "잘 보았구려" |
| 지도 모드 — 학습 항목 설명 | `~해요체` (유지) | "돌을 깨뜨려 도구를 만들었어요." |
| 개인정보 처리방침 · 오류 안내 · 접근성 문구 | **표준말** | "이름은 이 기기에만 저장됩니다." |

> **원칙** — 놀 때는 사극, 찾아볼 때는 쉬운 말, 알려야 할 때는 표준말.

### 1-2. 변환 규칙 (`tools/style-hao.mjs`)

결정적 어미 치환표 + 예외 목록. 변환기(`tools/convert.mjs`)가 콘텐츠 문서를
읽을 때 **탐험 모드 텍스트에만** 적용합니다.

```
~했어요   → ~하였소        ~이에요/예요 → ~이오
~해요     → ~하오          ~있어요      → ~있소
~까요?    → ~겠소?         ~인가요?     → ~이오?
~보세요   → ~보시오        ~마세요      → ~마시오
~네요     → ~구려          ~답니다      → ~이라오
~습니다   → ~소이다        ~하죠        → ~하오
```

- **고유명사·연도·수치·인용문은 건드리지 않습니다.**
- 치환 후 어색한 문장은 `tools/style-exceptions.json`에 원문→교정문으로 등록합니다.
  기계 치환 90 % + 손 교정 10 %를 전제로 하고, **시대별로 눈으로 읽어 검수**합니다.
- 변환은 빌드 타임 1회. 산출물 `js/eras/*.js`는 커밋되므로 앱에는 변환 코드가 없습니다.

## 3. 추가 요구 10건

### 3-1. 학생 이름 (요구 1)

```js
localStorage['atlasStudent_v1'] = {
  name: '홍길동',            // 빈 문자열 허용
  mascot: '두루',            // 고정
  agreedAt: '2026-08-28T…',  // 개인정보 고지 확인 시각
  startedAt: '…' }
```

- 인트로 첫 화면에서 입력. **`이름 없이 시작` 버튼을 같은 크기로 둡니다** — 이름은 선택입니다.
- 입력값은 화면 표시와 인쇄에만 씁니다. 네트워크로 나가는 경로가 코드에 존재하지 않습니다.
- **시대 리포트·탐험 기록지 머리말에 자동 삽입**: `이름 ______` 대신 실제 이름.
  이름이 비어 있으면 빈칸으로 인쇄됩니다.
- 설정에서 **이름 바꾸기 / 내 기록 모두 지우기**를 제공합니다.

### 3-2. 개인정보 처리방침 (요구 2)

- **첫 실행 시 1회 고지.** 확인해야 시작합니다. `agreedAt` 기록.
- 하단 상시 링크 `개인정보 처리방침`.
- **전부 표준말** (D1 예외).

### 3-3. 탐험 등급과 탐험가 유형 (요구 3)

**등급 — 발자국 5단계.** 누적 발견 수만 봅니다. **다른 학생과 비교하는 수치는 어디에도 없습니다.**

| 단계 | 이름 | 조건 |
|---|---|---|
| 1 | 🐾 설레는 첫걸음 | 첫 발견 |
| 2 | 🧭 궁금한 길잡이 | 10 |
| 3 | 🎒 씩씩한 탐험가 | 40 |
| 4 | ⏳ 슬기로운 시간여행자 | 100 |
| 5 | 📖 든든한 역사지기 | 180 |

승급 시 두루가 도장을 찍는 짧은 연출(1.2초)과 하오체 한 줄: "한 걸음 더 나아갔구려."

**탐험가 유형** — 행동 6축을 세어 상위 두 축의 조합으로 문구를 만듭니다.

| 축 | 세는 것 |
|---|---|
| 👀 관찰 | `inspect` 핫스팟 열람 수 |
| 🎮 도전 | 미니게임 성공 수 |
| 💬 이야기 | NPC 대사 열람 · `choice` 완료 수 |
| 🏺 수집 | 유물 아이템 · 학습 항목 수 |
| 🗺️ 탐사 | 방문 지역 수 · 관문 통과 수 |
| ✍️ 기록 | 서술형 답안 작성 수 |

출력 예: **"차근차근 살펴보는 유물 탐험가"** · **"발로 뛰며 이야기를 모으는 탐험가"**
표본이 적을 때(총 행동 10 미만)는 유형을 확정하지 않고 "아직 살펴보는 중이오"를 보여 줍니다.

### 3-4. 유물 가방 (요구 4·6)

**세 저장소를 분리합니다.**

| | 무엇 | 저장소 |
|---|---|---|
| 🎒 역사 가방 | 학습 항목 도감 (`contentId`) — 지도 모드와 공유 | `historyBagExplore_v1` (기존) |
| 🏺 유물 가방 | 시대의 **도구·유물 아이템** — 퀘스트 보상 | `relicBag_v1` * |
| 📔 스탬프 수첩 | 지역·시대 도장 | `stampBook_v1` * |

유물 아이템 정의는 시대 파일이 내보냅니다.

```js
export const RELICS_PALEO = [
  { id:'r-jumeok', icon:'🪓', name:'주먹도끼', era:'paleo',
    from:'jjenseokgi',                    // 이 퀘스트를 깨면 얻음
    line:'한쪽은 둥글고 한쪽은 뾰족하니, 이 하나로 가죽도 벗기고 뼈도 발랐소.' } ];
```

- 시대당 **6~12개**. 변환기가 `cat:'relic'`·`kind:'inspect'`·미니게임 퀘스트에서 후보를 뽑고,
  이름과 `line`은 손으로 다듬습니다.
- 가방 화면은 시대별 선반 그리드. **얻지 않은 칸도 실루엣으로 보여 줍니다**(무엇이 남았는지 알게).
- 인트로에서 두루가 가방을 **받는** 연출로 시작합니다(요구 6).

- 미니게임 앞에는 여전히 **선택형 문제가 먼저** 옵니다.
- 후삼국·개항기·6·25의 미니게임은 제한 없이 채웁니다.

### 3-9. 사진 관찰 임무 (요구 10)

**목표: 사진이 붙은 관찰 임무 40개 이상.**

관찰형(`inspect`)에 **"왜?"를 묻는 마무리 문제**를 넣습니다. 사용자가 든 예가 정확히 이 형식입니다.

```js
{ id:'bitsal-look', kind:'inspect', cat:'relic', icon:'🏺',
  title:'빗살무늬 토기를 살펴보다', img:['bitsal.jpg'],
  hotspots:[
    { label:'빗금이 촘촘한 겉면', note:'겉을 빗처럼 긁어 무늬를 냈소.' },
    { label:'뾰족한 밑바닥',      note:'평평하지 않고 뾰족하니, 바닥에 세울 수가 없소.' } ],
  capstone:{ text:'이 토기는 도무지 세울 수가 없소. 어찌하여 밑을 이리 뾰족하게 만들었겠소?',
             choices:['…','모래땅에 꽂아 세워 두고 썼기 때문','…','…'], correct:1,
             ok:'그러하오. 강가와 바닷가 모래에 밑을 박아 세워 두던 그릇이오.',
             no:'다시 보시오. 이 사람들이 어디에 살았는지를 떠올려 보시오.' } }
```

- 사진은 `assets/photos/*.jpg` 파일 우선, 없으면 **사진 칸 자체를 그리지 않습니다**(§9-3).
- 부족분은 `tools/fetch-photos.mjs`로 위키미디어 공용에서 수집(CC BY / CC BY-SA / CC0 / 공공누리 1유형만,
  가로 1200px 이하 webp, **사람이 눈으로 최종 확인**).
- 새 관찰 문항의 문체는 §1 규약(하오체)을 따릅니다.
