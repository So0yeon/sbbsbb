# 지도 모드 v2 — 시대별 영토 모핑

날짜 2026-08-28 · 브랜치 `map-v2` · 상태 확정

기존 지도 모드의 **지도 그림만** 다시 만듭니다. 직접 제작하신 시대별·국가별 영토를 얹고,
시대를 옮길 때 영토가 **차오르며 넓어지는** 연출을 붙이는 것이 목적입니다.

## 왜 새로 만드는가

지금 지도의 영토는 꼭짓점 7~10개짜리 손그림 폴리곤입니다(`js/map-data.js` 의 `terr`).
직접 만드신 GADM 기반 영토는 나라 하나가 폴리곤 수백 개로 이루어져 있어, 기존 표현으로는 담기지 않습니다.

## 지켜야 할 것 (기존 제약 그대로)

| 제약 | 뜻 |
|---|---|
| 서버 없음 · 외부 통신 0 | 폰트·라이브러리 전부 `vendor/`. CDN 금지 |
| 인터넷이 끊겨도 동작 | 정적 파일만 |
| 빌드 도구 없음 | `tools/` 의 node 스크립트는 **개발 전용**, 앱은 순수 정적 |
| 팀 분업 | **기존 파일을 고치지 않는다.** 새 파일만 추가한다 |

## 1. 작업 격리

`main` 에서 `map-v2` 브랜치를 따고 새 파일만 만듭니다. 팀원이 같은 시간에 탐험 모드
(`index.html` · `css/styles.css` · `js/engine/*`)를 고쳐도 충돌면이 없습니다.

```
map2.html                    인트로 없이 지도만 뜨는 페이지
css/map2.css                 v2 전용 스타일
js/map2/territory-data.js    자동 생성 — 시대별·나라별 영토 (전역 window.TERRITORY)
js/map2/morph.js             영토 모핑
js/map2/map2-app.js          지도 그리기 · 시대 이동 · 나라 등장/소멸
tools/gen-territory.mjs      GeoJSON → territory-data.js (개발 전용)
```

기존 파일 중 **읽기만 하는 것**: `js/atlas-geo.js`(실측 해안선), `js/map-data.js`(13시대 정의),
`vendor/font/pretendard.css`. 손대지 않고 `<script>` 로 부르기만 합니다.

유일한 기존 파일 수정은 `.gitignore` 에 `.superpowers/` 한 줄입니다.
나중에 합칠 때 `index.html` 에 링크 한 줄을 더하면 됩니다.

## 2. 좌표계

기존 투영식을 그대로 쓰되 **캔버스만 오른쪽으로 넓힙니다**. 7세기 발해가 경도 138.16까지 뻗기 때문입니다.

```
px(lng) = (lng - 115) * (800/22)      // 36.3636 px/도 — 기존과 동일
py(lat) = (49 - lat) * (902/19)       // 47.4737 px/도 — 기존과 동일
viewBox = 0 0 873 902                 // 기존 800×902 → 가로만 +73
```

기준점과 축척이 같으므로 **기존 지도의 모든 좌표가 그대로 유효합니다.** 나중에 합칠 때 값을 고칠 필요가 없습니다.

## 3. 자료 변환

`tools/gen-territory.mjs` 가 GeoJSON 19개를 읽어 `js/map2/territory-data.js` 로 굽습니다.

- 입력 경로는 인자로 받습니다. 원본 GeoJSON(약 14MB)은 저장소에 넣지 않습니다.
- Douglas–Peucker 로 단순화합니다. 닫힌 고리는 시작점과 끝점이 같아 그대로 넣으면 무너지므로,
  가장 먼 점에서 두 도막으로 잘라 각각 처리합니다.
- 화면에서 보이지 않는 조각(면적 2px² 미만)은 버립니다.
- 목표: 전체 150KB 이하. 원본은 173,000점입니다.

```js
window.TERRITORY = {
  meta: { lng0:115, lng1:139, lat0:30, lat1:49, w:873, h:902 },
  nations: { goguryeo:{ name:'고구려', color:'#4E7F6A' }, ... },
  frames: [
    { key:'c4', century:4, label:'4세기', eras:['three'],
      nations:[ { id:'goguryeo', d:'M…' }, ... ] }, ...
  ]
};
```

## 4. 시대 짜임

기존 13시대를 축으로 두고, 시대 안에서 세기가 흐릅니다. 학습 항목 166개의 연결이 그대로 유지됩니다.

| 시대 | 프레임 | 나라 |
|---|---|---|
| 구석기 · 신석기 | 없음 | 해안선만 |
| 청동기·고조선 | `c0` | 고조선 |
| **삼국시대** | `c4` → `c5` → `c6` | 고구려 · 백제 · 신라 · 가야 · 탐라 (6세기는 고구려·백제·신라) |
| 통일신라·발해 | `c7` | 발해 · 신라 |
| 후삼국 | `c10` | 발해 · 후백제 · 고려 · 신라 |
| 고려 | `c11` → `c12` | 고려 |
| 조선 전기 · 조선 후기 · 개항기 · 일제강점기 · 광복 · 6·25 | `c14` | 조선 |

- 6세기(신라 전성기)와 12세기 자료는 2026-08-28 저녁에 들어와 반영했습니다. 6세기에는 가야(562년 병합)와
  탐라 자료가 없어 그 장면에서는 세 나라만 나옵니다.
- 광복·6·25의 38선·휴전선은 이번 범위 밖입니다.

## 5. 전환 — 국가별 모핑

같은 나라가 다음 세기로 넘어갈 때 **모양이 흘러서 바뀝니다**. 차오름(tide-fill)은 쓰지 않습니다.

영토는 조각(본토·섬) 여러 개의 모음이고 조각 수가 세기마다 다릅니다 — 고구려는 4세기 2조각,
5세기 12조각, 6세기 7조각입니다. 그래서 `js/map2/morph.js` 가 이렇게 처리합니다.

| 단계 | 하는 일 |
|---|---|
| 짝짓기 | **가장 큰 조각(본토)끼리는 거리와 상관없이 먼저 묶습니다.** 7세기 만주의 발해가 10세기의 작은 영역으로 줄어도 사라졌다 다시 생기지 않고 이어집니다. 나머지 조각은 중심 거리와 넓이 비로 점수를 매겨 짝짓습니다 (150px 밖·점수 0.15 미만은 짝으로 보지 않습니다) |
| 점 맞추기 | 짝지어진 두 조각의 둘레를 같은 수로 나눠 점을 다시 뽑고, 시작점을 돌려 서로 맞춥니다 |
| 짝 없는 조각 | 새로 생긴 섬은 제 중심에서 펴지고, 없어진 섬은 제 중심으로 오므라듭니다 |

- 1.6초 · `easeInOutCubic`
- 나라가 새로 서면 중심에서 펴지며 나타나고, 나라 이름이 사라지면 오므라들며 사라집니다
- **조선 전기부터 6·25 까지는 영토가 같아 그 사이를 오갈 때만 전환을 두지 않습니다** (데이터의 `still`).
  고려 → 조선처럼 장면이 실제로 바뀔 때는 모핑합니다
- 나라가 앞선 나라를 이어받으면(조선 ← 고려, 데이터의 `after`) 사라졌다 생기지 않고
  영토가 그대로 흘러가며 색이 물듭니다
- `prefers-reduced-motion: reduce` 이면 모핑 없이 바로 바꿉니다. 머리말의 「모핑 켜기/끄기」 단추와
  `?motion=on|off` 로 언제든 바꿀 수 있습니다
- 색은 반드시 CSS 규칙으로 지정합니다. `fill="var(--x)"` 처럼 속성에 직접 쓰면 브라우저가 무시합니다

## 5-1. 라벨

나라 이름을 **가장 큰 조각의 중심**에 띄웁니다. 모핑하는 동안 라벨도 같은 곡선으로 따라 움직이고,
확대·축소해도 글자 크기는 화면에서 일정하게 유지됩니다 (배율에 맞춰 글자 크기를 되돌립니다).

같은 나라라도 장면마다 이름표를 달리 붙일 수 있습니다. 신라는 삼국 → 통일신라 → 후삼국까지
**한 나라로 이어 모핑하되**, 7세기 장면에서만 이름표를 「통일신라」로 답니다.

## 5-2. 확대 · 이동

바퀴로 확대·축소(가리킨 자리 기준), 끌어서 이동, 두 손가락으로 벌리고 오므리기, 오른쪽 아래 ＋ － ⤢.
⤢ 는 그 시대 전체가 들어오도록 되돌립니다. 시대를 바꾸면 자동으로 그 시대에 맞춰집니다.

## 6. 화면

이번에는 지도 그림에 집중합니다.

- 위: 시대 이름 · 세기 표시 · 나라 범례(그 프레임에 있는 나라만)
- 가운데: 지도. 해안선(실측 530점) 위에 영토
- 아래: 13시대 타임라인. 시대를 고르면 그 시대의 첫 프레임부터 재생되고,
  시대 안에 프레임이 여럿이면(삼국 4→5, 고려 11→12) 이어서 재생됩니다. 세기 점으로 직접 고를 수도 있습니다

기존 지도 모드에서 **v2 에 없던 것만** 옮겨 왔습니다 (`js/map2/panel.js`).
원본 `js/map-app.js` 는 손대지 않았습니다.

| 옮겨 온 것 | 안 옮긴 것 (v2 와 겹침) |
|---|---|
| 분류 필터 6종 · 항목 목록 · 상세 시트(사진·출처·태그·이어 볼 이야기) | 영토 그리기 |
| 지도 위 항목 마커(겹침 회피 라벨·발견 표시) | 나라 이름 라벨 |
| 교류선 · 이웃 나라 이름 · 수도 | 연표 · 확대·이동 |

- 필터는 지도 왼쪽 위에 얹었습니다
- 목록에서 항목을 눌러도 **지도는 움직이지 않습니다** (보던 자리를 잃지 않게)
- 마커 라벨은 나라 이름·수도·이웃 나라가 차지한 자리를 비켜 갑니다
- 딸린 파일은 전부 읽기만 합니다 — `store.js` `atlas-content.js` `atlas-photos.js`
  `asset-credits.js` `atlas-dedupe.js`

## 7. 검증

- `map2.html?selftest=1` — 프레임을 전부 돌며 렌더하고, 나라 수와 path 길이를 콘솔에 출력. 오류 0
- 기존 `bash tools/check.sh` 와 같은 방식(헤드리스 Chrome 콘솔 검사)으로 확인
- 눈으로: 4세기 → 5세기에서 고구려가 남쪽으로 넓어지는 것이 보이는가

## 8. 알려진 한계

- 영토는 현대 행정구역(GADM)의 합집합입니다. 실제 국경선과 정확히 같지 않습니다
- `7silla` 는 속성이 `제주특별자치도 · base_year 2025` 이고 위도 42.3까지 올라갑니다.
  `10balhae` 는 평양 북쪽의 작은 덩어리입니다. 둘 다 **의도한 표기** 라는 확인을 받고 그대로 씁니다
- 6세기에는 가야·탐라 자료가 없어 그 장면에서만 두 나라가 빠집니다
